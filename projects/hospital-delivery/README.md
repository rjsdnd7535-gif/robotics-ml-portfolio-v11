# 병원 배송로봇 · 좌표를 몰라도 장소 이름으로 배송 요청

**문제 정의** 사람은 “약국으로 가 줘”라고 말하지만, 주행 노드에는 지도상의 목표 좌표가 필요하다. 장소 해석이 실패했을 때까지 이동 명령을 보내면 어느 좌표로 가야 할지 정할 수 없다.

**해결 방법** Python 명령 노드에서 자연어 요청을 등록된 장소 이름과 대조했다. 확인된 이름만 ROS 2 목적지 토픽으로 보내고, 주행 노드는 장소 목록에서 좌표를 조회해 Nav2 목표를 생성한다. LLM 호출 예외가 발생하면 키워드로 다시 찾고, 그래도 목적지가 없으면 상태만 알리고 반환한다.

**확인 결과** Gazebo 병원 환경에서 자연어로 요청한 장소의 좌표까지 이동하는 동작을 본인이 확인했다. 예외 처리 분기는 코드에서 확인했다. 반복 주행 횟수와 성공 건수를 기록하지 않아 성공률은 미측정이다.
